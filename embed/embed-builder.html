Disclaimer

Base64 can be decoded: a font put in the code this way is not protected from being copied. If your font is commercial and this is a concern, use a version made for testing (for example a subset or a demo version).

Chosen files are only used in the preview. Press “Add as Base64” to put a file in the code, or upload it to your site and add its URL instead.

The preview downloads URL fonts from this page. If one fails here (CORS), it can still work on your site when the font is on the same domain as the page.

The Font tab lists these fonts in this order (drag the handle), with the names you give them (empty = the font’s own name). The first one is shown at start.

Tests

Reshape & add first turns Arabic letters into their presentation forms (isolated, initial, medial, final, lam-alef), in case you use a subset version of a font (for example made with pyftsubset).

Drag the handle to change the order (or focus it and use ↑ ↓). Checked tests appear in the Test tab in this order; the first one opens at start.

OpenType features

Checked features appear in the OpenType tab. The On / Off button sets how each one starts; visitors can still switch it. Your fonts’ features are listed by themselves; shaping features (init, medi, fina…) start unchecked.

The OpenType tab shows the features of the font on display, with an “All” button for the shaping features.
